<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Vercel Lambda → Aiven MySQL | Production DB traffic over the public internet; must be verified TLS |
| Operator CLI → Aiven MySQL | One-shot migration over TLS from the operator's machine |
| Vercel dashboard env vars → Lambda | DB credentials injected at runtime; never committed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2-05 | Information Disclosure / Spoofing | Lambda → Aiven connection (MITM) | mitigate | TLS with `MYSQL_ATTR_SSL_VERIFY_SERVER_CERT => true` against the committed CA (D-05). Task 3 DB-01 check asserts no SSL error / no insecure-transport in logs. |
| T-2-06 | Information Disclosure | DB credentials in Vercel / .env | mitigate | Credentials set only as Vercel env vars + gitignored local `.env`; Task 1 acceptance asserts no credential value is committed. Only the public CA cert is committed. |
| T-2-07 | Denial of Service (broken deploy) | CA cert excluded from Lambda bundle | mitigate | Task 1 confirms `certs/` not in `.vercelignore`; DB-01 log check would surface a missing-cert SSL error. |
| T-2-08 | Integrity | seed/demo data in production | mitigate | Task 2 only runs `bin/migrate.php` (schema.sql); acceptance asserts no `demo@test.fr` user in Aiven (D-08). |
| T-2-SC | Tampering | npm/composer package installs | accept | No package installs this phase — operator provisioning + config only. No legitimacy checkpoint required. |

Deferred (NOT Phase 2 blockers): connect-timeout/retry tuning and ProxySQL pooling (D-10/D-11, v2/OPS); graceful 503 page (keep existing friendly 500); preview-deploy DB isolation.
</threat_model>
