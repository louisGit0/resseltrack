| ProductController → Product model | trusted; all writes use raw PDO prepared statements scoped by :uid |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Elevation of Privilege (IDOR) | rate() — POST /products/{id}/rate | mitigate | rate() re-validates ownership via `$this->products->find($pid, Auth::id()) === null` → redirect before any write; setRating() also scopes its UPDATE with `AND user_id = :uid` (defense in depth) |
| T-09-02 | Spoofing (CSRF) | rate() state-changing POST | mitigate | `Csrf::validate()` is the first line of rate() (419 on mismatch), same convention as every other POST action |
| T-09-03 | Tampering (injection / bad data) | rating + rating_note input | mitigate | rating cast to int and range-checked (1-5 or NULL); rating_note bound via prepared statement (no concatenation); empty rating → NULL clears the rating |
| T-09-SC | Tampering | composer/npm installs | accept | no dependency changes in this phase — no install tasks |
</threat_model>
